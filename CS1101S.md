## Substitution models
Applicative order: arguments are evaluated first
- primitive expressions - take the value
- operator combinations - evaluate operands, apply operator
- declaration assignment - evaluate expression and replace name by value
- function application - evaluate component expression

Normal order: arguments are passed as is to the function

## Resource functions
For program P solving problem of size n:
- Let r(n) denote amount of a resource (time/space) that P needs

Big theta notation
$$E=mc^2$$
- A resource function has order of growth $\theta(g(n))$ $\exists k_1, k_2, n_0$ such that $k_1g(n) < r(n) < k_2g(n)$
    - Big O notation is only lower bounded
    - Big $\omega$ is only upper bounded
